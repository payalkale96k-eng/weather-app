🌤️ Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript.

✨ Features

- 🔍 Search weather by city
- 🌡️ Temperature
- 💧 Humidity
- 💨 Wind speed
- ☁️ Weather condition
- 📱 Responsive design

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeather API

🚀 How to Run

1. Add your OpenWeather API key in "script.js".
2. Open "index.html" in your browser.
3. Search for any city.
